# Font sources

Inter 400/500/600/700: downloaded 2026-11-09 from the official Google Fonts CSS endpoint and fonts.gstatic.com. Full font files include Cyrillic. SIL OFL license: Inter-OFL.txt, obtained from https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt.

Oddval SemiBold (600), Version 1.000, Type Forward (Stan Partalev, Mirela Belova): author listing https://www.dafont.com/oddval.font supplies the same SHA-256 font as https://www.1001fonts.com/oddval-font.html. Package https://www.1001fonts.com/download/oddval.zip includes 1001fonts-oddval-eula.txt, preserved here as Oddval-LICENSE.txt. That bundled license explicitly permits web-app embedding (section 6) and webfont conversion (section 4). Font file has not been modified or converted. Only the font needed by this application is included; no font download feature is provided.

Do not replace this font with the Type Forward website's tester or trial font: those are a different distribution with different terms. Other paid Oddval weights are not included.
